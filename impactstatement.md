# HEW Talent Matching - Change Impact Assessment

## 1. Requested Change

The Associate Dean of Corporate Relations has requested that the HEW Talent Matching system be expanded to include a virtual recruitment and interviewing platform.

The requested features include live WebRTC video interviews, automatic interview recording, and AI-generated speech and sentiment summaries for recruiters.

## 2. Impact on Project Scope

The original project focuses on student profiles, job postings, talent matching, skill-gap analysis, interview scheduling, and placement analytics.

The requested changes would significantly expand the project by adding live video communication, recording storage, and AI analysis capabilities.

These features are not included in the original project scope.

## 3. Impact on Schedule

The project currently uses three two-week sprints.

Adding the requested features would require additional development and testing time. The team estimates that the changes could require another two or three sprints beyond the original schedule.

This could delay the completion of the existing project requirements.

## 4. Impact on Cost and Resources

The requested changes would require additional resources, including:

- Video communication technology using WebRTC.
- Storage for recorded interviews.
- AI tools for speech transcription and analysis.
- Additional development and testing time.
- Security measures to protect interview recordings.

These requirements could increase the project's operating costs and workload.

## 5. Technical Impact

The development team would need to integrate live video communication into the existing platform.

The system would also need to support recording interviews, storing video files, converting speech into text, and generating AI summaries.

These additions would increase the technical complexity of the project.

## 6. Risks

The requested changes introduce several risks:

- Delays to the existing project schedule.
- Increased development complexity.
- Additional costs for storage and AI processing.
- Privacy and security concerns involving recorded interviews.
- Potential inaccuracies or bias in AI-generated sentiment summaries.
- Additional testing requirements.

## 7. Benefits

The requested features could provide several benefits:

- Students could attend interviews remotely.
- Employers could conduct interviews directly through the platform.
- Recruiters could review recorded interviews.
- AI-generated summaries could help recruiters review interview content more efficiently.

## 8. Recommendation to the Change Control Board

**Recommendation: Defer**

Our team recommends deferring the requested changes until after the original three sprints have been completed.

The new features could improve the HEW Talent Matching platform, but they would significantly increase the project scope, technical complexity, and resource requirements.

Deferring the changes would allow the team to complete the original project requirements before expanding the platform.

The requested features could be considered for a future development phase after additional planning, cost estimation, and security review.

## 9. Conclusion

The proposed changes could improve the recruitment process, but implementing them during the current project would create additional risks.

Our team recommends completing the original HEW Talent Matching system first and reviewing the requested changes as a future project expansion.

## CCB Decision

Decision: Defer

The Change Control Board decided to defer the proposed WebRTC video interviewing, automatic recording, and AI sentiment analysis features until after the original project is completed.

The team will continue working on the existing Sprint 2 backlog without adding the new features. These changes may be considered in a future development phase.
